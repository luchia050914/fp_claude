# FP2級 再挑戦ドリル

2026年11月のFP2級（学科＋実技「資産設計提案業務」）再受験に向けた、Androidタブレット用のオフライン問題集です。HTML・CSS・JavaScriptだけで動き、サーバー・有料サービス・外部ライブラリ・CDNは使いません。

- アプリ版：1.0.0
- 問題データ：2026-10-26版（オリジナル31問）
- 法令基準日：2026年4月1日（2026年6月以降のCBT試験の基準とされる日付）

## 1. ファイル構成

```
fp2-drill/
├── index.html          画面の骨組み
├── styles.css          見た目（大きな文字、押しやすいボタン、ダークモード）
├── app.js              出題・採点・履歴・設定・書き出し/読み込み
├── questions.json      問題データ（ここを編集すれば問題を追加・修正できる）
├── manifest.json       インストール用の情報（アプリ名・アイコン）
├── service-worker.js   オフライン用キャッシュ（バージョン付き）
├── README.md           この説明書
└── icons/
    ├── icon-192.png
    ├── icon-512.png
    └── icon-maskable-512.png
```

アイコン3点はインストール（ホーム画面に追加）に必要なため、`icons` フォルダごと置いてください。

## 2. 機能

- 学科6分野＋実技・計算の分野選択（「最優先2分野」「学科6分野」「実技・計算」「すべて」の一括選択つき）
- 5つのモード：弱点集中／ランダム／模擬試験／間違えた問題／お気に入り
- 四択問題と数値入力問題（全角数字・カンマ入力も可）
- 回答後に正解・解説・計算手順・間違えやすいポイント・出典と基準時点を表示
- 分野別正答率、全体正答率、回答数、連続正解数（現在・最高）、直近7日間の回答数
- 間違えた回数が多い問題ほど再出題されやすい重み付け（弱点集中では金融・不動産をさらに優先）
- お気に入り登録と復習画面
- 学習履歴のリセット（2回確認）
- ダークモード（端末に合わせる／ライト／ダーク）と文字サイズ3段階
- オンライン／オフライン表示
- 学習データのJSON書き出し・読み込み、問題JSONの追加読み込み
- 学科・実技それぞれの試験日と残り日数の表示
- 途中経過の自動保存（「中断」してもホームの「続きから」で再開）

学習データは端末内の localStorage に保存されます。外部に送信されることはありません。

## 3. Androidタブレットへの導入手順（初心者向け）

PWAはインターネット上の「https://」のページからでないとインストールできません。いちばん簡単なのは、次の章のGitHub Pagesで無料公開する方法です。

1. パソコンで下記「5. GitHub Pagesで無料公開する手順」を行い、`https://ユーザー名.github.io/fp2-drill/` のようなURLを用意します。
2. タブレットで **Chrome** を開き、そのURLにアクセスします。
3. ページが表示されたら、そのまま10秒ほど待ちます（裏でオフライン用のデータが保存されます）。
4. 右上の「︙」メニューをタップし、「**アプリをインストール**」または「**ホーム画面に追加**」を選びます。
5. 確認画面で「インストール」をタップすると、ホーム画面に「FP2ドリル」のアイコンができます。
6. 以後はアイコンから起動します。ブラウザのアドレスバーがない全画面で開けば成功です。
7. 最初に「設定」タブで学科・実技の受検日を入力してください。ホームに残り日数が出ます。

補足：パソコンからファイルをコピーして `file://` で開く方法では、オフライン機能（Service Worker）とインストールが働きません。必ず https で公開したURLから開いてください。

## 4. オフライン動作の確認手順

1. オンラインの状態でアプリを1回起動し、ホーム画面が出るまで待ちます。
2. 念のため、一度アプリを閉じてもう一度起動します（キャッシュが確実に有効になります）。
3. タブレットを機内モードにするか、Wi‑Fiとモバイルデータをオフにします。
4. ホーム画面のアイコンからアプリを起動します。
5. 右上の表示が「**オフラインで動作中**」になっていて、問題を解けることを確認します。
6. 何問か解いて「成績」タブの回答数が増えれば、オフラインでも記録が保存されています。
7. 機内モードを解除すると、表示が「オンライン」に戻ります。

パソコンのChromeで確認する場合：F12で開発者ツール →「Application」→「Service Workers」で `service-worker.js` が「activated and is running」になっていること、「Cache storage」に `fp2drill-v1.0.0` があることを確認し、「Network」タブで「Offline」を選んで再読み込みします。

## 5. GitHub Pagesで無料公開する手順

1. https://github.com でアカウントを作ります（無料）。
2. 右上の「＋」→「New repository」。Repository name に `fp2-drill` と入力し、**Public** を選んで「Create repository」。
3. 作成した画面の「uploading an existing file」をクリックします。
4. パソコンのフォルダから `index.html`、`styles.css`、`app.js`、`questions.json`、`manifest.json`、`service-worker.js`、`README.md` と、**`icons` フォルダごと**ドラッグ＆ドロップします。
5. 下の「Commit changes」を押します。
6. リポジトリの「Settings」→ 左メニュー「Pages」。「Build and deployment」の Source を「Deploy from a branch」、Branch を「main」「/(root)」にして「Save」。
7. 1〜3分待つと、同じ画面の上部に `https://ユーザー名.github.io/fp2-drill/` が表示されます。これがアプリのURLです。

注意：Publicリポジトリの内容は誰でも見られます。問題データに個人情報を書かないでください。学習データ（正答率など）は端末内にだけ保存され、GitHubには送られません。

### 更新するとき

1. 変更したファイルを同じ手順でアップロード（上書き）します。
2. **`service-worker.js` の `CACHE_VERSION` を必ず上げます**（例：`v1.0.0` → `v1.0.1`）。
3. タブレットでアプリを開くと、上部に「新しいバージョンがあります。更新する」が出るので、タップします。

`questions.json` だけを直した場合も、`CACHE_VERSION` を上げておくと確実です（問題データはネットワーク優先で取得するため、オンラインで起動すれば上げなくても反映されます）。

## 6. 問題データ（questions.json）の書き方

```json
{
  "id": "FIN-101",
  "category": "finance",
  "difficulty": 2,
  "type": "choice",
  "question": "問題文",
  "choices": ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"],
  "answer": 1,
  "explanation": "詳しい解説",
  "formula": "計算式（なければ空文字）",
  "pitfalls": "間違えやすいポイント",
  "baseDate": "2026-04-01",
  "lawSensitive": true,
  "sources": [
    { "title": "出典名", "url": "https://...", "checkedDate": "2026-10-26", "note": "何を確認したか" }
  ],
  "tags": ["NISA"]
}
```

| 項目 | 内容 |
|---|---|
| id | 重複しない問題ID。分野の略号＋番号がおすすめ（FIN・RE・LP・RM・TX・IN・PR） |
| category | `finance` 金融資産運用／`realestate` 不動産／`life` ライフプランニング／`risk` リスク管理／`tax` タックスプランニング／`inheritance` 相続・事業承継／`practical` 実技・計算 |
| difficulty | 1〜3 |
| type | `choice`（選択式）または `numeric`（数値入力） |
| choices | 選択式のみ。2〜6個 |
| answer | 選択式は正解の番号（**0から数える**。1つ目が0）。数値入力は正解の数値 |
| numeric | 数値入力のみ。`{"unit":"万円","tolerance":0,"hint":"例：480"}`。tolerance は許容誤差（小数の答えは 0.005 など） |
| baseDate | 根拠となる制度の基準時点 |
| lawSensitive | 税率・控除額・年金額など法改正で変わる内容なら true。画面で強調表示されます |
| sources | 公的機関の出典。確認していない場合は `checkedDate` を `null` にすると、画面に「未確認」と表示されます |

追加の方法は2つあります。

- **questions.json を直接編集**して再アップロード（全員に反映。`CACHE_VERSION` も上げる）
- アプリの「設定」→「JSONを読み込む」で問題JSONを読み込む（その端末だけに追加。同じIDは上書き）

### 出典の確認状況（2026-10-26時点）

確認日が入っている出典は、公的機関（国税庁・金融庁・財務省・厚生労働省・自治体の建築基準法資料など）の公開情報と内容を照合済みです。確認日が「未確認」の出典（借地借家法、民法の遺留分、死亡保険金の課税関係、一時所得、損益通算、贈与税の速算表、角地の建ぺい率緩和）は、一般に知られた原則に基づいて作成していますが、受験前に記載のURLで確認してください。

## 7. よく起こる不具合と直し方

| 症状 | 原因 | 直し方 |
|---|---|---|
| 「問題データを読み込めませんでした」と出る | questions.json がない、JSONの書式ミス（カンマ抜け・最後の要素の後ろのカンマなど） | 同じフォルダにあるか確認。https://jsonlint.com などで書式チェック。エラーの行を直す |
| 一部の問題だけ出ない | 必須項目の不足（answer の番号が範囲外など） | 画面上部のエラー表示の件数を確認し、README 6章の項目を見直す |
| 「アプリをインストール」が出ない | `file://` で開いている／http で開いている／アイコンがない | https のURL（GitHub Pages）から開く。`icons` フォルダがアップロードされているか確認 |
| 更新したのに古いまま | Service Worker のキャッシュが残っている | `CACHE_VERSION` を上げて再アップロード→アプリ上部の「更新する」をタップ。それでもだめなら Chrome の「設定→サイトの設定→保存されているデータ」から該当サイトを削除 |
| オフラインで開けない | 一度もオンラインで完全に読み込んでいない | オンラインで1回起動して10秒待ち、アプリを開き直してから試す |
| GitHub Pages で404 | Pages の設定前、またはファイルがフォルダの中に入っている | Settings→Pages の設定を確認。`index.html` がリポジトリの一番上の階層にあるか確認 |
| 学習データが消えた | Chromeの閲覧データ削除、アプリのアンインストール | 定期的に「学習データを書き出す」でバックアップし、「JSONを読み込む」で戻す |
| 書き出したファイルが見つからない | ダウンロードフォルダに保存されている | 「ファイル」アプリ→「ダウンロード」を確認 |
| 数値入力が不正解になる | 単位の違い（円と万円）、四捨五入の位置 | 入力欄右の単位と、問題文の端数処理の指示を確認 |
| 文字が小さい・大きすぎる | 端末の表示設定 | 「設定」→「文字の大きさ」で3段階から選ぶ |

## 8. 追加問題を作るときのプロンプト

AIに追加問題を作ってもらうときは、次の文をそのまま貼り付けて【 】を書き換えてください。出力されたJSONをファイルに保存し、アプリの「設定」→「JSONを読み込む」で追加できます。

```
あなたはFP2級（学科・実技「資産設計提案業務」）の問題作成者です。
次の条件で、完全オリジナルの練習問題を作成してください。

【分野】【finance / realestate / life / risk / tax / inheritance / practical のいずれか】
【テーマ】【例：債券の利回り計算、容積率、損益通算】
【問題数】【例：5問】（四択と数値入力をおおむね半々）
【難易度】【1〜3】
【IDの開始番号】【例：FIN-101】
【法令基準日】2026-04-01

守ること：
1. 実際の試験問題・過去問・市販問題集の文章を転載・言い換えしない。数値や登場人物は独自に設定する。
2. 税率・控除額・年金額などは、法令基準日時点の制度に基づく。法改正で変わる内容は lawSensitive を true にする。
3. 数値や制度を断定する場合は、国税庁・金融庁・厚生労働省・日本年金機構・財務省・e-Gov法令検索などの公的機関の公開情報で確認し、sources に出典名・URL・確認日（YYYY-MM-DD）・確認内容を記録する。確認できなかった場合は checkedDate を null にし、note に「要確認」と書く。
4. 四択は正解が1つだけになるようにし、誤りの選択肢はよくある勘違いを反映させる。
5. 数値入力は単位と端数処理（四捨五入の位置など）を問題文に明記し、numeric に unit・tolerance・hint を入れる。
6. 解説（explanation）、計算手順（formula、改行は \n）、間違えやすいポイント（pitfalls、箇条書きは「・」と \n）を必ず書く。
7. 出力は次の形式のJSONだけにする（前後に説明文やコードブロック記号を付けない）。answer は選択式なら0始まりの番号。

{
  "questions": [
    {
      "id": "", "category": "", "difficulty": 1, "type": "choice",
      "question": "", "choices": ["", "", "", ""], "answer": 0,
      "explanation": "", "formula": "", "pitfalls": "",
      "baseDate": "2026-04-01", "lawSensitive": false,
      "sources": [{ "title": "", "url": "", "checkedDate": null, "note": "" }],
      "tags": []
    },
    {
      "id": "", "category": "", "difficulty": 2, "type": "numeric",
      "question": "", "numeric": { "unit": "万円", "tolerance": 0, "hint": "例：100" }, "answer": 0,
      "explanation": "", "formula": "", "pitfalls": "",
      "baseDate": "2026-04-01", "lawSensitive": false,
      "sources": [], "tags": []
    }
  ]
}

最後に、作成した全問について「正解が1つに定まるか」「計算結果が正しいか」を自分で検算し、誤りがあれば直してから出力してください。
```

生成された問題は、読み込む前に正解と出典を必ず自分でも確認してください。

## 9. 免責

収録問題は学習用のオリジナル問題です。実際の試験の出題内容・形式を保証するものではありません。制度の内容は基準時点のもので、その後の改正が反映されていない場合があります。
